# Higher Resolution Script

The experimental higher-resolution workflow uses:

```text
Upscale-HigherResolution.ps1
```

The script accepts one of three target resolutions:

```text
2K
4K
8K
```

All targets preserve the original 4:3 presentation.

| Target | Output |
|---|---:|
| `2K` | `2048x1536` |
| `4K` | `2880x2160` |
| `8K` | `5760x4320` |

---

## Source Requirement

> [!IMPORTANT]
> Higher-resolution editions should be generated from the **original SD source files**.

Do not use the existing 1080p remaster as the source for another AI generation.

Preferred:

```text
Original SD
    |
    v
Real-ESRGAN
    |
    v
Target resolution
```

Avoid:

```text
Original SD
    |
    v
1080p AI Remaster
    |
    v
4K AI Remaster
    |
    v
8K AI Remaster
```

Using the original source avoids accumulating:

- previous AI-generated detail
- HEVC compression artefacts
- sharpening
- ringing
- line distortion
- repeated AI hallucination

# 2K Usage

Generate a 2K 4:3 edition:

```powershell
.\Upscale-HigherResolution.ps1 `
    -SourceDir "D:\Anime\BB保你大" `
    -RealESRGANDir "C:\Real-ESRGAN" `
    -Target 2K
```

Output:

```text
2048x1536
```

Default encoding:

```text
HEVC
x265
preset slow
CRF 20
```

Default output directory:

```text
D:\Anime\BB保你大\Upscaled-2K
```

# Custom Output Directory

The destination can be overridden:

```powershell
.\Upscale-HigherResolution.ps1 `
    -SourceDir "D:\Anime\BB保你大" `
    -OutputDir "E:\BB-4K" `
    -RealESRGANDir "C:\Real-ESRGAN" `
    -Target 4K
```

---

# Custom CRF

The defaults are:

| Target | Default CRF |
|---|---:|
| 2K | 20 |
| 4K | 19 |
| 8K | 18 |

A different CRF can be supplied:

```powershell
.\Upscale-HigherResolution.ps1 `
    -SourceDir "D:\Anime\BB保你大" `
    -RealESRGANDir "C:\Real-ESRGAN" `
    -Target 4K `
    -CRF 20
```

Lower CRF values generally produce:

```text
higher quality
larger files
```

Higher values generally produce:

```text
smaller files
more compression
```

# Resume from an Episode

As with the 1080p workflow:

```powershell
-StartEpisode 42
```

can be used after an interruption.

Example:

```powershell
.\Upscale-HigherResolution.ps1 `
    -SourceDir "D:\Anime\BB保你大" `
    -RealESRGANDir "C:\Real-ESRGAN" `
    -Target 4K `
    -StartEpisode 42
```

The selected episode is treated as a fresh restart point.

# Processing Method

For a typical 640x480 source, all three modes initially perform the same AI operation:

```text
640x480
    |
    v
Real-ESRGAN AnimeVideoV3 x4
    |
    v
2560x1920
```

The AI result is then resized for the requested edition.

## 2K

```text
2560x1920
    |
    v
Lanczos downscale
    |
    v
2048x1536
```

## 4K

```text
2560x1920
    |
    v
Lanczos resize
    |
    v
2880x2160
```

## 8K

```text
2560x1920
    |
    v
Lanczos resize
    |
    v
5760x4320
```

Only **one AI generation** is performed.

This is intentional.

The script does not repeatedly pass an already AI-generated image through Real-ESRGAN.

---

# Why 4K and 8K Are Not Multiple AI Passes

A workflow such as:

```text
640x480
  -> AI x4
2560x1920
  -> AI x4
10240x7680
```

would involve applying the AI model to details that were themselves already generated by AI.

That risks amplifying:

- fake texture
- halos
- unstable line work
- compression defects
- invented facial details
- temporal inconsistency

For this workflow, one AI reconstruction from the original source is preferred.

---

# Recommended Testing

Do not immediately process all 52 episodes at a new resolution.

Start with:

```powershell
-StartEpisode 1
```

and temporarily test one episode.

Compare:

```text
Original SD
1440x1080 current remaster
2048x1536 2K
2880x2160 4K
5760x4320 8K
```

Particular attention should be paid to:

- character outlines
- eyes and facial features
- Japanese title cards
- flat-colour animation areas
- fast movement
- dark scenes
- compression noise
- line stability between frames

If the higher-resolution version does not produce a meaningful visual improvement, the current 1440x1080 master should remain the preferred edition.
